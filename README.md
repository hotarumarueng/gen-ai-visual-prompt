# gen-ai-visual-prompt

画像・動画・資料・LP を生成AIで作るときの指示文（プロンプト）を、デザイン・撮影・映像の「型」で組み立て、出てきた結果を完成チェックで見て、直す指示を1つずつ出す Claude Code スキル。

## 何をするか

- **道筋A 新しく指示文を作る**：目的の6項目（作るもの・見る人・載せる文言・生成AIの種類・縦横比か尺・枚数）を確かめ、分野と型を1つ選び、その型の「指定する要素」をすべて埋めた指示文を書く。完成チェックと、直す指示の候補を1つ添える。
- **道筋B 出てきた結果を直す**：結果を完成チェックで見て、外れた点を1つ選び、残す部分を先に書いて変える条件を1つだけ書いた指示を出す。直った結果も同じチェックで見直す。

用語は3つ。

| 用語 | 意味 |
|---|---|
| 型 | 余白・三分割構図・ドリーインのように、名前の付いた作り方のパターン。10分野×10個 |
| 指定する要素 | その型を使うとき、指示文に必ず入れる項目 |
| 完成チェック | 出てきた結果が狙いどおりかを見る観点 |

## 分野

| ファイル | 分野 | 使う生成AI |
|---|---|---|
| `references/design.md` | バナー・告知画像のデザイン | 画像生成 |
| `references/composition.md` | 写真風画像の構図 | 画像生成 |
| `references/slide-layout.md` | 資料1枚のレイアウト | 資料・図解・Web |
| `references/camera-work.md` | 動画のカメラワーク | 動画生成 |
| `references/lp-parts.md` | LP のパーツ | 資料・図解・Web |
| `references/diagram.md` | 図解の型 | 資料・図解・Web |
| `references/background.md` | 背景 | 画像生成 |
| `references/lens.md` | 写真のレンズと画角 | 画像生成 |
| `references/lighting.md` | 動画の光 | 動画生成 |
| `references/art-style.md` | イラストの画風 | 画像生成 |

`SKILL.md` は全分野に共通する手順だけを持ち、分野ごとの型は `references/` に分けている。Claude は必要な分野のファイルだけを読む。

## 入れ方

Claude Code のスキルフォルダに、このリポジトリをそのまま置く。

- 個人で使う：`~/.claude/skills/gen-ai-visual-prompt/`
- プロジェクトで使う：`<プロジェクト>/.claude/skills/gen-ai-visual-prompt/`

置いたあと、「DMのバナーの指示文を作って」「この画像、余白が詰まってるのを直したい」のように頼むと、Claude がこのスキルを選んで使う。名前を出して「gen-ai-visual-prompt を使って」と頼んでもよい。

## 確かめたこと

- 名前を出さない頼み方（作る依頼1本・直す依頼1本、どちらもデザイン分野）で、スキルが自動で呼ばれ、道筋A・B がそれぞれ使われた（2026-11-18）
- 未確認：デザイン以外の分野の頼み方での自動呼び出し。出てきた指示文を実際の生成AIに送った結果
